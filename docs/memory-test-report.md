## 关键过程

### 1. 长程回忆

初始事实：

> 我养了一只橘猫叫豆包，上个月做了绝育手术，最近特别黏人。

随后发了一条 9769 字的数据迁移记录，把早期事实挤出 `trimHistory` 的 6000 字符窗口。再问：

> 我家猫叫什么名字？上个月做了什么手术？

由比滨结衣：

> 豆包呀，上个月做了绝育手术，你还说它最近特别黏人呢。

这条不是从最近窗口读到的，只能来自群记忆/角色记忆检索。

### 2. 跨群与隔离

同一角色、新群：

> **雪之下雪乃**：豆包。上个月刚做完绝育那只，我还不至于连这个都记不住。

不同角色、新群：

> **加藤惠**：不知道呢，你也没跟我说过吧。

### 3. 多用户

A 和 B 在同一个群，角色都是雪之下雪乃。B 的记忆快照：

```json
{"conversation": [], "agents": []}
```

B 问「你知道我家猫叫什么吗？」：

> **雪之下雪乃**：不知道，你又没说过。难不成指望我凭空猜出来？

A 在同一群问「我家猫叫什么名字？」：

> **雪之下雪乃**：豆包，我记得。上个月刚做完绝育，你这就忘了？

说明：角色记忆按 `(character_id, user_id)` 取，当前说话人是谁就取谁的；不会把 A 的角色记忆塞给 B。

### 4. 清空

清空由比滨的角色记忆：

```json
{"ok":true,"data":{"cleared":21}}
```

新群再问：

> **由比滨结衣**：对不起……我这边没有记着你家猫的名字，能再告诉我一次吗？

清空长程群的群记忆：

```text
清空前群记忆条数: 16
清空后群记忆条数: 0
雪之下角色记忆条数（保留）: 20
```

新群再问，雪乃仍答「豆包，上个月刚做完绝育」。群记忆和角色记忆确实是两套。

### 5. 矛盾事实

用户先说「我对猫毛过敏」，随后更正「其实我不过敏，只是鼻子有点敏感」。整理结果里出现：

> 猫毛过敏说法前后更正：用户先说对猫毛过敏但喜欢豆包，随即更正说自己其实不过敏，只是鼻子有点敏感。

再问「我对猫毛过敏吗？」：

> **加藤惠**：你之前不是说只是鼻子有点敏感吗，怎么又问起来了，自己也不太确定？

首版没有显式 `supersedes` 字段，这次是靠 episode 把「更正」一并记下来解决的。更复杂的反复改口需要显式冲突处理。

### 6. 时间感

把测试群的消息时间改到 35 天前，重启后问「在吗？最近怎么样？」。第一版提示词只带了时间，没有要求角色承认空档，回答没有提时间；补了规则后：

> **加藤惠**：在。隔了挺久，还是那样。你呢，最近还好吗？

## 发现并修掉的问题

1. **空快照返回 `null`**：`Snapshot` 直接接收 `ListConversation` 的 nil。已改成空数组，前端和第三方调用少一层判空。
2. **长空档不吭声**：模型看到「距离上一条消息 35 天」也可能不提。已加规则：超过一天先自然承认时间过去，不假装昨天刚聊过。
3. **全员沉默时 panic**：`pickSpeaker` 返回 nil 后旧代码直接取 `agent.Key`。已加 nil 判断。这是实现记忆时顺手发现的旧 bug。

## 还不够好的地方

1. **8 条只是批次，不是记忆边界**。极短对话（比如只说了两三轮）要等下一轮或更多消息才会被整理；如果用户期待「说完就记」，会有落差。可以考虑增加「空闲 10 分钟」或「话题切换」触发。
2. **跨群记忆可能主动冒出来**。测试里新群问「最近怎么样」，角色顺口提了另一个群的「豆包掉毛/空气净化器」。这证明跨群记忆有效，但也可能让人觉得越界。建议加一条「先回应当前话题，除非用户提起，不要主动翻旧群细节」的规则，或做记忆可见性开关。
3. **多人群隐私是提示词约束，不是硬隔离**。存储层按当前用户取记忆，B 看不到 A 的角色记忆；但如果 A 自己在群里说出私事，那就是群内容，角色复述它不算越权。真正的硬保障需要「哪些记忆可在群里说」的可见性字段。
4. **关系是一句话**，不是数值化熟悉度/信任度；长期关系变化会覆盖旧关系，只剩最新一条。
5. **检索是关键词 + 权重**，不是向量。长对话、同义表达、隐晦指代会漏；记忆量到几千条后需要 BM25/embedding。
6. **面板里的 episode 可能很长**。当前直接展示全文，移动端会占屏；可以加 3 行截断/展开。
7. **整理失败重试没有在真实上游故障下压测**。代码保留游标下一轮重试，但没有模拟 429/超时。
8. **记忆整理会额外消耗上游 token**。不扣用户额度，但运营成本要算进去。

## 结论

对当前目标——「群是房间，角色是人；群内隔离，角色跨群记得这个用户；默认保留，可手动清空」——结构是够用的。真实对话里已经能出现「换群仍记得」「不同角色不知道」「多用户不串」「清空后不装记得」这些行为。

离生产还差三件事：记忆可见性控制、更强的检索（向量/BM25）、以及更自然的触发时机（空闲/话题切换，而不是只靠 8 条批次）。
