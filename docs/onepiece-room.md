# 草帽一伙 · 伟大航路

一个固定的 One Piece 群聊场景。目标不是“让模型扮演动漫角色”，而是让十个角色知道**自己是谁、彼此是什么关系、经历过什么、哪些事不知道**，再用自己的语气说话。

## 时间线

**和之国大战结束 → 刚离开和之国 → 蛋头岛尚未发生。**

为什么固定在这里：

- 这是草帽一伙人数、悬赏、四皇格局都稳定下来的节点。
- 再往后（蛋头岛/未来岛/最终章）剧情还在推进，模型很容易把不同时间点混在一起。
- 角色可以聊路飞五档、索隆阎魔、山治杰尔马、甚平加入、红色历史正文，但不会提前知道后面的事。

用户问「后来呢」时，角色应该说「还没发生/没听说」，而不是编未来。

## 共享世界设定

`Scenario.World` 里写了一份共享设定，只进系统提示，不通过 API 暴露：

- 世界常识：伟大航路、新世界、四皇、海军、世界政府、王下七武海废除、革命军、恶魔果实、霸气、历史正文、空白一百年、古代兵器、D之一族、拉夫德鲁、ONE PIECE。
- 和之国后的格局：路飞成为四皇；凯多、大妈被打败；桃之助成为将军；大和暂留和之国；普鲁顿在和之国；路飞觉醒五档/尼卡；索隆用阎魔；山治觉醒杰尔马体质但拒绝战斗服；甚平正式加入；十个人的悬赏。
- 共同经历：东海到和之国的航路。
- 知识边界：每个人知道的细节不同；不要百科式背诵；不要承认漫画/动画/作者。

## 路由：点名谁，谁先答

`addressedAgentsOrdered` 会按名字/外号在句子里出现的位置排序：

- 「甚平，你怎么看现在的四皇格局？」→ 甚平先答。
- 「布鲁克，你怎么看罗宾？」→ 布鲁克先答，罗宾后答（因为“布鲁克”出现得更早）。
- 「你们怎么看？」→ 不误判为点名，按正常发言选择。

外号也识别：路飞/船长/草帽、索隆/绿藻头、山治/厨子/卷眉毛、乔巴/狸猫、罗宾/恶魔之子、甚平/海侠等。

## 实测

用真实 DeepSeek 跑过这些问题：

- 「路飞，你的五档到底是怎么回事？」→ 路飞先答“变得超自由，头发变白，像太阳”；没有百科式解释原理。
- 「甚平，你怎么看现在的四皇格局？」→ 甚平先答“路飞、香克斯、黑胡子、巴基”，并判断黑胡子最危险。
- 「罗宾，历史正文和空白一百年有什么关系？」→ 罗宾用“钥匙/门”回答，没有一次倒完设定。
- 「布鲁克，拉布还在等你吗？」→ 布鲁克提到双子岬和五十年的约定，情感线接住了。
- 「乔巴，你还记得希鲁鲁克医生吗？」→ 乔巴回答“他救了我的命，教了我什么叫真正的医生”。
- 「山治，All Blue 真的存在吗？」→ 山治说“我信它存在，不然这十几年算什么”。
- 「娜美，贝尔梅尔是个什么样的人？」→ 娜美回答“嘴上凶，心里软，为了我和诺琪高连命都不要”。

## 已修的问题

1. **点名被其他人抢答**：原先随机选人，问“甚平怎么看”可能五个人抢答，甚平没开口。已加点名优先。
2. **一句话两个名字的顺序**：问“布鲁克，你怎么看罗宾”原先罗宾先答；已按出现位置排序。
3. **口癖串台**：弗兰奇曾用罗宾的“fufu”；已加“只用自己的口癖”规则，并在弗兰奇人设里明确。
4. **布鲁克把女性叫“先生”**：已明确对女性用“小姐”。
5. **把听说说成亲眼见过**：罗宾曾声称见过耶稣布；已加“听来的就说听说，不要装熟”。
6. **具体细节编造**：乌索普曾把德雷斯罗萨说成“德罗斯罗萨”；已加译名表和“记不清就说记不清”。

## 怎么改

- 换时间线/加设定：改 `Scenario.World`。
- 改角色：改 `onepieceScenario.Agents[i].Prompt`。
- 加角色/外号：加 `Agent` 和 `Aliases`；`ResolveAgents` 会自动派生 `onepiece:<key>` 作为跨群记忆身份。
- 测试：`go test ./internal/service -run 'TestOnePiece|TestAddressed'`。
