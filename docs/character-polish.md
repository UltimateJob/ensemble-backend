# 角色检索润色

![检索润色](polish.png)

## 解决什么问题

用户输入一个名字，例如「漩涡鸣人」，希望直接得到一个能进群聊的完整角色，而不是只有名字和几个关键词。

难点是：

- 同名角色很多（「小樱」可以是春野樱，也可以是木之本樱）。
- 长连载角色有多个时期（少年篇/疾风传/成年）。
- 动漫、电视剧、电影、公众人物的资料结构不一样。
- 模型可能为了“显得懂”而编造。

所以这个功能不是“名字 → 一段泛泛人设”，而是：

1. 本地角色库先精确命中；
2. 模型做有边界的考据；
3. 低置信度按“没找到”处理；
4. 让用户补来源/作品/时期；
5. 输出结构化资料 + 可直接进群的 prompt。

## 输入

`POST /v1/agents/polish`

```json
{
  "name": "漩涡鸣人",
  "source": "火影忍者",
  "kind": "anime",
  "note": "疾风传时期"
}
```

- `name`：必填，角色名/公众人物名。
- `source`：来源/作品/职业。强烈建议填写，用于消歧。
- `kind`：`anime` / `tv` / `movie` / `celebrity` / `game` / `other`。
- `note`：可选，时期、版本、只想保留哪套人设。

## 输出

找到：

```json
{
  "found": true,
  "confidence": "high",
  "agent": {
    "name": "漩涡鸣人",
    "title": "九尾人柱力 · 木叶忍者",
    "source": "火影忍者（疾风传）",
    "kind": "anime",
    "prompt": "你是漩涡鸣人……",
    "profile": {
      "era": "疾风传时期",
      "identity": "木叶隐村忍者，九尾人柱力",
      "personality": "外向、嘴硬、不服输、怕孤独",
      "speech": "语速快、短句、感叹号多……",
      "relationships": "佐助、小樱、卡卡西、伊鲁卡、自来也……",
      "abilities": "影分身、螺旋丸、九尾查克拉……",
      "backstory": "……",
      "emotionalCore": "不想再一个人",
      "boundaries": "不背叛同伴……",
      "sampleLines": ["说到做到，这就是我的忍道！"]
    }
  }
}
```

找不到：

```json
{
  "found": false,
  "confidence": "low",
  "message": "无法确认「不存在角色XYZ」是任何可识别的动漫角色……请提供规范全名、真实作品名、版本信息……"
}
```

前端会把 `message` 直接显示在表单下方，不清空用户输入，方便补来源再试。

## 检索策略

1. **本地角色库精确匹配**：例如「雪之下雪乃」。命中后把作品、标签、语气作为线索交给模型，减少跑偏。
2. **模型考据**：只允许高置信度的公开信息；名字有歧义且来源为空/对不上时，返回 `found:false` 或 `confidence:low`。
3. **低置信度即未找到**：不会把 `low` 的结果硬塞给用户。
4. **本地库兜底**：如果模型请求失败但本地库精确命中，返回基础人设（`confidence:medium`），至少可用。

当前**没有接实时联网搜索**，检索基于本地角色库 + 模型知识。冷门/新角色可能找不到；这时来源和补充说明就很重要。后续可以接搜索 API，并在 profile 里返回引用来源。

## 角色卡字段

- `era`：采用的时期/版本。
- `identity`：身份、所处世界。
- `personality`：性格与矛盾。
- `speech`：语气、句长、称呼、口头禅。
- `relationships`：重要关系。
- `abilities`：能力/特长。
- `backstory`：关键经历。
- `emotionalCore`：情感核心/执念/软肋。
- `boundaries`：绝不做的事、知识边界。
- `sampleLines`：语气示例。
- `prompt`：最终给群聊用的第二人称提示词，300-600 字。

## 实测

| 输入 | 结果 |
|---|---|
| 漩涡鸣人 + 火影忍者 + 疾风传 | 命中；标题「九尾人柱力·木叶忍者」；prompt 写到达不到的火影、九尾、影分身、螺旋丸、伊鲁卡、自来也、佐助、孤独感 |
| 漩涡鸣人 + 空来源 | 命中；模型自动补「火影忍者」，并给出成年/七代目火影版本 |
| 小樱 + 火影忍者 | 命中春野樱（医疗忍者、第七班、纲手弟子） |
| 小樱 + 魔卡少女樱 | 命中木之本樱（库洛牌、星之杖、小可、知世） |
| 华妃 + 甄嬛传 | 命中年世兰；年家、欢宜香、对皇上痴情、骄纵 |
| 周杰伦 + 华语歌手 | 命中；只写公开音乐人形象，明确不聊私生活/争议 |
| 雪之下雪乃 + 空来源 | 本地库命中，再由模型补成完整人设 |
| 不存在角色XYZ + 测试作品 | `found:false`；说明无法确认，并建议补规范名/作品/版本 |

## 已知边界

1. **模型知识有时效**：新番、刚完结的剧、冷门角色可能检索不到。补充来源/时期能提高命中率。
2. **版本歧义**：长连载角色默认选主线代表阶段；用户可以在 `note` 指定「疾风传」「成年」「只保留剧版」。
3. **真人只写公开形象**：不写私生活、不写未经证实的争议，保持尊重。
4. **不是实时搜索**：目前没有联网检索与引用；后续接搜索 API 后可以把来源链接一并返回。
5. **仍可能有细节漂移**：输出是模型考据，不是官方设定集；用户可以编辑后再存入角色库。后续可以在 UI 里加「逐项校对/编辑 profile」。
