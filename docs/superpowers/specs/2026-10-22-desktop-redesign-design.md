# 智团桌面端改版设计

> 日期：2026-10-22
> 状态：已与产品确认，进入实施
> 范围：PC 端全套 16 屏 + macOS 桌面壳重做

## 1. 目标

把现在的「单聊天页 + 一堆弹层」改造成 Meta Muse 风格的
**左侧固定导航 + 中间主内容 + 右侧可收起工作面板** 三栏 PC 工作台，
同时修好桌面壳「双击不可用」的全部工程问题。

不做：移动端布局重做、密码登录、深色主题、团队计费。

## 2. 关键决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 视觉 | 全面切蓝色扁平 | 产品确认；logo 同步重做蓝色稿 |
| 头像 | 全部预生成黏土 3D | 接口已验证可用；用气质描述生成原创肖像，不复刻受版权保护角色 |
| 登录 | 保留手机号/邮箱 + 验证码 | 不加密码体系，只重做视觉 |
| 代码工作室 | 右侧 Agent 面板 + 房间内全宽视图 | 保留现有执行器能力，不塞进窄面板 |
| 群聊行为 | 有 Run 在跑的角色静默（只亮脉冲环），讨论轮照常 | 达到设计稿的「埋头干活」，不牺牲群聊生命力 |
| 前端技术 | vanilla JS + ES modules，无构建 | 保持零构建、E2E 可直接跑 |
| 路由 | hash 路由 | 无服务端改动，`?c=` 旧链接可重定向 |

## 3. 信息架构

```
#/lobby              团队大厅
#/room/:id           聊天房间（四类房间差异化）
#/goals              目标看板
#/connectors         连接器
#/library            资料库
#/settings           设置 / 个人中心
#/404                404
```

左导航 232px：logo、六个导航项、「聊天房间」内联展开房间列表、底部用户入口。
右面板 380px（可展 480px），默认收起，边缘 12px 手柄；三种模式：
Agent 工作面板 / 目标详情 / 产物预览。全局单例。

旧 `?c=<id>` 与 `#/c/<id>` 一律重定向到 `#/room/<id>`。

## 4. 视觉系统

token 集中在 `web/app/css/tokens.css`：

| token | 值 |
|---|---|
| `--pri` | `#367BED` |
| `--bg` | `#FFFFFF` |
| `--surface` | `#F7F7F8` |
| `--line` | `#EDEDF0` |
| `--tx` / `--tx-2` / `--tx-3` | `#1A1A1D` / `#5A5A63` / `#86868B` |
| `--ok` / `--warn` / `--bad` | `#4CAF50` / `#E6A23C` / `#F56C6C` |
| `--r-lg` / `--r-md` | `20px` / `12px` |
| `--sh` | `0 2px 10px rgba(0,0,0,.06)` |

- 图标统一 `stroke-width: 2`、无填充
- 无渐变、无发光、无深色主题
- 状态色只用于环/点/图标；正文对比度不足时用深色变体
  （`--ok-tx:#2E7D32` 等）。设计稿的 `#4CAF50` 在白底仅 2.7:1。

**logo**：保留「星团」形态（中心大星 + 环绕小星），改为蓝色扁平单色，
去掉渐变底。`logo.svg` / `logo-dark.svg` / `logo-mono.svg` / `favicon.svg` 四份同步，
官网、运维台、登录页、桌面图标共用。

## 5. 页面规格

### 5.1 团队大厅 `#/lobby`

- 标题「团队大厅」+ 右上蓝色按钮「新建自定义团队」
- 区块一「开箱即用预设团队」：3 列卡片网格，卡片含黏土群像封面、
  标题、简介、角色头像组、「加入团队」
- 区块二「我的自定义团队」：列表行，含团队头像、名称、角色数、
  最近活跃、`进入房间`
- 预设团队 = 现有 6 个场景（bid / code / xhs / research / anime / companion）
- 「加入团队」= 以该场景创建会话并进入房间；创建前用弹窗确认群名与模型

### 5.2 聊天房间 `#/room/:id`

- 顶栏：团队名 + 横向头像条（含 2px 状态环）+ 右侧面板开关
- 消息流：用户右侧气泡、Agent 左侧气泡、任务同步卡全宽 `#F7F7F8`
- 任务同步卡：`🔵执行中 / 🟢已完成 / 🔴待审批` + 标题 + 预览 + 展开
- 底部输入条：`@` 唤起成员选择、附件、发送
- 四类房间视觉一致，内容不同：
  - 竞标审核团队（bid）：产出文档卡
  - 小红书创作团队（xhs）：markdown 笔记卡
  - 代码开发工作室（code）：代码/接口卡，房间内可展开全宽工作区视图
  - 草帽一伙（anime/onepiece）：更松弛的间距与气泡
- 有 Run 在跑的角色头像亮 2px 蓝色脉冲环，且不参与该轮闲聊发言

### 5.3 目标看板 `#/goals`

- 顶部 tab「进行中 / 待规划」，视图切换「看板 / 列表」
- 看板三列：todo / doing / done，卡片可拖拽改状态
- 卡片：目标标题、指派角色头像组、描述、细进度条、展开详情
- 右侧面板：子任务与执行日志（关联 Run 的时间线）
- 进度来自 `service.GoalProgress` 的派生值；手动设过就显示手动值

### 5.4 连接器 `#/connectors`

- 两组：「团队公共连接器」「我的私有连接器」
- 行：服务图标、名称、描述、开关、`查看权限`
- 点行展开权限预览 popover（列出该连接器暴露给 Agent 的字段）
- `probe` 按钮做真实连通性测试，结果写回 `status/lastError`

### 5.5 资料库 `#/library`

- 顶部筛选：按团队、按类型（标书/文案/代码/图片/其他）
- 网格卡片：大预览、文件名、产出 Agent、时间、`打开预览`
- 右侧面板大预览：markdown 渲染、表格、代码高亮、图片
- 支持下载（桌面壳走 `WKDownloadDelegate`）

### 5.6 设置 / 个人中心 `#/settings`

- 顶部资料卡：头像、昵称、账号、会员标记
- 分组列表：个人资料、头像、账号安全、消息通知、隐私、退出登录
- 头像可在「预设」与「上传」间选；上传走本地存储（不新增后端接口）

### 5.7 新建自定义团队弹窗

- 团队名称、简介、角色列表（每行：黏土头像、名称、职责、删除）
- 「添加新角色」复用现有锻造（角色库搜索 / 自造 / 检索润色）
- 底部取消 / 保存

### 5.8 审批弹窗（全局）

- 居中模态：标题「需要你的审批」、操作说明、命令/摘要预览、风险提示
- 按钮：蓝色「允许本次执行」、灰色「拒绝」；展开项「本任务都允许」
- `runs.js` 统一订阅所有活跃 Run，任何页面都能弹
- 窗口不在前台时发原生通知（桌面壳）

### 5.9 团队设置右滑面板

- 修改名称、更换封面、查看全部角色、复制模板、解散团队

### 5.10 登录页

- 白底、居中卡片、20px 圆角、柔和阴影
- logo + 标语 + 手机号/邮箱切换 + 验证码 + 蓝色登录按钮
- 保留演示账号提示与 `devCode` 自动填

### 5.11 新手引导

- 首次登录后全屏蒙版，四步：新建团队 → 头像状态条 → 点开头像开面板 → 目标卡
- 可跳过；完成状态存 `localStorage`

### 5.12 空状态合集

六种：暂无团队 / 暂无对话 / 暂无目标 / 暂无连接 / 暂无产出 / 搜索无结果。
统一组件 `emptyState(icon, title, sub, action)`。

### 5.13 全局组件

成功/失败 Toast（右上浮动）、骨架屏（浅灰 shimmer）、
权限拒绝弹窗、404 页。

## 7. 桌面壳

| 项 | 做法 |
|---|---|
| 二进制定位 | `Bundle.main.executableURL` 同目录 `ensemble` |
| 静态资源 | build.sh 拷 `web/` 到 `Contents/Resources/web/`；`webDir()` 增加该路径 |
| 配置 | 依次加载 `~/Library/Application Support/智团/.env`、仓库根 `.env`，注入子进程 |
| 数据 | 默认 `~/Library/Application Support/智团/data` |
| 端口 | 探测 8080–8099，选空闲端口，`ADDR` 传给子进程 |
| 图标 | build.sh 由 logo 生成 `AppIcon.icns` |
| 后端失败 | 内置错误页：原因 + 重试 + 打开日志 |
| 下载/新窗口 | `WKUIDelegate` + `WKDownloadDelegate` |
| 窗口记忆 | `setFrameAutosaveName` |
| 多开 | 已有实例则激活 |
| 菜单 | 重载 ⌘R、选目录 ⌘O、前往 ⌘1–⌘6、右面板 ⌘0、缩放、开发者工具 |
| 通知 | 审批出现且窗口不在前台时发本地通知 |

## 12. 已知取舍

1. 状态色对比度不足时用深色变体，视觉上与设计稿有细微差异。
2. 群聊仍保留「角色自主发言」，未完全按设计稿的「默认静默」。
3. 头像为原创气质肖像，不是角色原作还原。
4. 不引入前端构建工具；文件拆分靠 ES modules。
5. 上传头像存 `localStorage`，不新增后端存储。
